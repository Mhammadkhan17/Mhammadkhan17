## How I work

- **Ship the smallest thing that solves the real problem**, then iterate on what users actually do. v1.1 beats v1.0.
- **Write code for the person who inherits it** — clear naming, simple abstractions, and notes on the why.
- **Pick proven tools over trending ones.** A well-chosen index outlives a new framework.
- **Name the tradeoff.** I recommend a path, say what we give up, and leave the final call to you.
